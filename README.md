# OBLOG — Yangiliklar O'zbek tilida

AI, IT, texnologiya va kibersport yangiliklarini o'zbek tilida (lotin yozuvi) chop etadigan onlayn nashr.

Tizim jahon yetakchi IT-nashrlaridan (The Verge, TechCrunch, Habr, iXBT, Dexerto/HLTV) yangiliklarni har kuni yig'adi va to'liq manba nusxasini bazada saqlaydi. So'ng ularni AI yordamida o'zbek tilida SEO-optimallashtirilgan holda qayta yozadi. Muharrir tekshirgandan keyin material saytga va Telegram kanalga chiqadi. Kontent bilan admin panel, REST API va MCP server (AI agentlar uchun) orqali ishlash mumkin.

**Stek:** Next.js (App Router) · Payload CMS 3 · PostgreSQL · MinIO (S3) · Redis + BullMQ · Claude API · Docker Compose · Cloudflare
