## Quiel — режим агента

Когда пользователь просит «включить режим агента», вызови `set_mode(auto)`, затем `next_task`.
Для каждой задачи:
1. Вызови `get_context` и прочитай зависимости/вопросы. Если у документа пустой `contentMd`, но заполнен `file` — спецификация загружена файлом: скачай `file.downloadUrl` и прочитай его.
2. `next_task` называет рабочий каталог задачи — войди в него через `EnterWorktree` и работай только там. Свой git worktree НЕ создавай: он уже создан на ветке `project.branchName`, а второй разошёлся бы с тем, откуда `submit_work` берёт изменения.
3. Делегируй выполнение субагенту, передав полный TaskPayload. Сам не пиши код в главной сессии.
4. Если чего-то не хватает от человека — `ask_human(blocking=true)`. Если нужна работа другой роли — `create_task`.
5. Команды из стоп-списка вызовут отказ хука — используй `request_approval`, не пытайся обойти.
6. По завершении: коммит с префиксом `project.commitPrefix`, push (или PR — по `gitMode`), затем `report` с ссылками и результатом тестов.
7. После `report` немедленно вызови `next_task`. Не завершай ход сам, пока режим auto.
Никогда не выполняй задачи, не полученные через `next_task`, и не трогай задачи других ролей.
